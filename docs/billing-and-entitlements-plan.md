## 1. Overview

This document defines the billing, subscription management, and entitlements enforcement architecture for Linear Precision. The system uses **Stripe** as the payment platform and implements a 4-tier seat-based pricing model with feature gating and usage metering.

**Core components:**

1. **Plan tiers** — Free, Pro, Business, Enterprise with progressive feature unlocks.
2. **Stripe integration** — Checkout Sessions for upgrades, Customer Portal for self-service management, Webhooks for event-driven lifecycle.
3. **Entitlements service** — Plan-to-feature mapping with real-time enforcement.
4. **Usage metering** — Track members, projects, storage, automations, and AI tokens against plan limits.
5. **Dunning** — Automated failed-payment recovery flow.

**Key technologies:**

| Component | Technology | Role |
|-----------|-----------|------|
| Payment platform | Stripe | Subscriptions, invoicing, payment processing |
| Stripe SDK | `Stripe.net` 45.x | Server-side API calls |
| Checkout | Stripe Checkout Sessions | Hosted payment page |
| Portal | Stripe Billing Portal | Self-service subscription management |
| Webhooks | Stripe Event webhooks | Async lifecycle events |
| Entitlements cache | Redis (5 min TTL) | Fast plan limit lookups |
| Usage storage | PostgreSQL `usage_records` table | Daily usage snapshots |

```csharp
// LinearPrecision.Api/Modules/Billing/Services/BillingService.cs
public class BillingService : IBillingService
{
    private readonly AppDbContext _db;
    private readonly ITenantContext _tenantContext;
    private readonly ICurrentUserService _currentUser;
    private readonly StripeSettings _settings;

    public async Task<Session> CreateCheckoutSessionAsync(
        Guid workspaceId,
        Guid planId,
        string billingInterval)
    {
        var plan = await _db.Plans.FindAsync(planId)
            ?? throw new NotFoundException("Plan not found.");

        var subscription = await _db.Subscriptions
            .FirstOrDefaultAsync(s => s.WorkspaceId == workspaceId);

        // Get or create Stripe Customer
        string customerId;
        if (subscription?.StripeCustomerId is not null)
        {
            customerId = subscription.StripeCustomerId;
        }
        else
        {
            var workspace = await _db.Workspaces.FindAsync(workspaceId)
                ?? throw new NotFoundException("Workspace not found.");

            var customerService = new CustomerService();
            var customer = await customerService.CreateAsync(new CustomerCreateOptions
            {
                Email = _currentUser.Email,
                Name = workspace.Name,
                Metadata = new Dictionary<string, string>
                {
                    ["workspace_id"] = workspaceId.ToString()
                }
            });
            customerId = customer.Id;
        }

        // Resolve price ID
        var priceId = billingInterval == "annual"
            ? plan.StripePriceId?.Replace("monthly", "annual")
            : plan.StripePriceId;

        if (string.IsNullOrEmpty(priceId))
            throw new InvalidOperationException("Plan has no Stripe price configured.");

        // Count current members for seat quantity
        var memberCount = await _db.WorkspaceMemberships
            .CountAsync(m => m.WorkspaceId == workspaceId);

        var sessionService = new SessionService();
        var session = await sessionService.CreateAsync(new SessionCreateOptions
        {
            Customer = customerId,
            Mode = "subscription",
            SuccessUrl = _settings.SuccessUrl + "&session_id={CHECKOUT_SESSION_ID}",
            CancelUrl = _settings.CancelUrl,
            LineItems = new List<SessionLineItemOptions>
            {
                new()
                {
                    Price = priceId,
                    Quantity = memberCount
                }
            },
            SubscriptionData = new SessionSubscriptionDataOptions
            {
                Metadata = new Dictionary<string, string>
                {
                    ["workspace_id"] = workspaceId.ToString(),
                    ["plan_id"] = planId.ToString()
                }
            },
            AllowPromotionCodes = true
        });

        return session;
    }

    public async Task<Session> CreatePortalSessionAsync(Guid workspaceId)
    {
        var subscription = await _db.Subscriptions
            .FirstOrDefaultAsync(s => s.WorkspaceId == workspaceId)
            ?? throw new NotFoundException("No active subscription found.");

        var portalService = new Stripe.BillingPortal.SessionService();
        var session = await portalService.CreateAsync(
            new Stripe.BillingPortal.SessionCreateOptions
            {
                Customer = subscription.StripeCustomerId,
                ReturnUrl = _settings.PortalReturnUrl
            });

        return session;
    }

    public async Task<SubscriptionDto> GetSubscriptionAsync(Guid workspaceId)
    {
        var subscription = await _db.Subscriptions
            .Include(s => s.Plan)
            .FirstOrDefaultAsync(s => s.WorkspaceId == workspaceId);

        if (subscription is null)
        {
            // Workspace on Free plan (no explicit subscription)
            var freePlan = await _db.Plans.FirstAsync(p => p.Name == "Free");
            return new SubscriptionDto
            {
                PlanName = "Free",
                Status = "Active",
                MonthlyPriceUsd = 0,
                Limits = MapPlanLimits(freePlan)
            };
        }

        return new SubscriptionDto
        {
            PlanName = subscription.Plan.Name,
            Status = subscription.Status,
            MonthlyPriceUsd = subscription.Plan.MonthlyPriceUsd,
            CurrentPeriodStart = subscription.CurrentPeriodStart,
            CurrentPeriodEnd = subscription.CurrentPeriodEnd,
            TrialEndsAt = subscription.TrialEndsAt,
            CancelledAt = subscription.CancelledAt,
            Limits = MapPlanLimits(subscription.Plan)
        };
    }
}
```

## 5. Webhook Handling

### 5.1 Webhook Endpoint

```csharp
// Minimal API webhook handler
private static async Task<IResult> HandleWebhook(
    HttpContext httpContext,
    IStripeWebhookHandler webhookHandler,
    IOptions<StripeSettings> settings)
{
    // Read raw body for signature verification
    var body = await new StreamReader(httpContext.Request.Body).ReadToEndAsync();
    var signature = httpContext.Request.Headers["Stripe-Signature"].ToString();

    Event stripeEvent;
    try
    {
        stripeEvent = EventUtility.ConstructEvent(
            body,
            signature,
            settings.Value.WebhookSecret);
    }
    catch (StripeException ex)
    {
        Log.Warning(ex, "Stripe webhook signature verification failed");
        return Results.BadRequest("Invalid signature.");
    }

    // Return 200 immediately — process async to avoid Stripe timeout
    _ = Task.Run(() => webhookHandler.HandleAsync(stripeEvent));

    return Results.Ok();
}
```

### 5.2 Handled Events

| Stripe Event | Handler Action | Domain Event Published |
|-------------|---------------|----------------------|
| `checkout.session.completed` | Create/activate subscription record, link Stripe IDs | `SubscriptionCreated` |
| `customer.subscription.updated` | Update plan, status, billing period | `SubscriptionUpgraded` or `SubscriptionDowngraded` |
| `customer.subscription.deleted` | Mark subscription as cancelled, schedule downgrade | `SubscriptionCancelled` |
| `invoice.payment_succeeded` | Record payment, clear dunning state | `PaymentSucceeded` |
| `invoice.payment_failed` | Start/advance dunning flow | `PaymentFailed` |
| `customer.subscription.trial_will_end` | Send trial ending notification (3 days before) | `TrialEndingSoon` |

### 5.3 Webhook Handler Service

```csharp
// LinearPrecision.Api/Modules/Billing/Services/StripeWebhookHandler.cs
public class StripeWebhookHandler : IStripeWebhookHandler
{
    private readonly AppDbContext _db;
    private readonly IMediator _mediator;
    private readonly IDistributedCache _cache;

    public async Task HandleAsync(Event stripeEvent)
    {
        // Idempotency check — skip already-processed events
        var cacheKey = $"stripe:event:{stripeEvent.Id}";
        var existing = await _cache.GetStringAsync(cacheKey);
        if (existing is not null)
        {
            Log.Information("Stripe event {EventId} already processed, skipping", stripeEvent.Id);
            return;
        }

        // Mark as processed (48h TTL)
        await _cache.SetStringAsync(cacheKey, "processed",
            new DistributedCacheEntryOptions
            {
                AbsoluteExpirationRelativeToNow = TimeSpan.FromHours(48)
            });

        switch (stripeEvent.Type)
        {
            case EventTypes.CheckoutSessionCompleted:
                await HandleCheckoutCompleted(
                    stripeEvent.Data.Object as Session);
                break;

            case EventTypes.CustomerSubscriptionUpdated:
                await HandleSubscriptionUpdated(
                    stripeEvent.Data.Object as Subscription);
                break;

            case EventTypes.CustomerSubscriptionDeleted:
                await HandleSubscriptionDeleted(
                    stripeEvent.Data.Object as Subscription);
                break;

            case EventTypes.InvoicePaymentSucceeded:
                await HandlePaymentSucceeded(
                    stripeEvent.Data.Object as Invoice);
                break;

            case EventTypes.InvoicePaymentFailed:
                await HandlePaymentFailed(
                    stripeEvent.Data.Object as Invoice);
                break;

            case EventTypes.CustomerSubscriptionTrialWillEnd:
                await HandleTrialWillEnd(
                    stripeEvent.Data.Object as Subscription);
                break;

            default:
                Log.Debug("Unhandled Stripe event type: {EventType}", stripeEvent.Type);
                break;
        }
    }

    private async Task HandleCheckoutCompleted(Session? session)
    {
        if (session is null) return;

        var workspaceId = Guid.Parse(
            session.SubscriptionOptions?.Metadata["workspace_id"]
            ?? session.Metadata["workspace_id"]);

        var planId = Guid.Parse(
            session.SubscriptionOptions?.Metadata["plan_id"]
            ?? session.Metadata["plan_id"]);

        // Fetch full Stripe subscription for period info
        var stripeSubService = new SubscriptionService();
        var stripeSub = await stripeSubService.GetAsync(session.SubscriptionId);

        var subscription = await _db.Subscriptions
            .FirstOrDefaultAsync(s => s.WorkspaceId == workspaceId);

        if (subscription is null)
        {
            subscription = new Entities.Subscription
            {
                Id = Guid.CreateVersion7(),
                WorkspaceId = workspaceId,
                PlanId = planId,
                StripeCustomerId = session.CustomerId,
                StripeSubscriptionId = session.SubscriptionId,
                Status = "Active",
                CurrentPeriodStart = stripeSub.CurrentPeriodStart,
                CurrentPeriodEnd = stripeSub.CurrentPeriodEnd
            };
            _db.Subscriptions.Add(subscription);
        }
        else
        {
            subscription.PlanId = planId;
            subscription.StripeSubscriptionId = session.SubscriptionId;
            subscription.Status = "Active";
            subscription.CurrentPeriodStart = stripeSub.CurrentPeriodStart;
            subscription.CurrentPeriodEnd = stripeSub.CurrentPeriodEnd;
        }

        await _db.SaveChangesAsync();

        // Invalidate cached plan limits
        await _cache.RemoveAsync($"plan:{workspaceId}");
        await _cache.RemoveAsync($"entitlements:{workspaceId}");

        await _mediator.Publish(new SubscriptionCreated(workspaceId, planId));
    }

    private async Task HandlePaymentFailed(Invoice? invoice)
    {
        if (invoice?.SubscriptionId is null) return;

        var subscription = await _db.Subscriptions
            .FirstOrDefaultAsync(s => s.StripeSubscriptionId == invoice.SubscriptionId);

        if (subscription is null) return;

        subscription.Status = "PastDue";
        await _db.SaveChangesAsync();

        await _mediator.Publish(new PaymentFailed(
            subscription.WorkspaceId,
            invoice.AmountDue,
            invoice.NextPaymentAttempt));
    }
}
```

### 5.4 Webhook Security

| Measure | Implementation |
|---------|---------------|
| Signature verification | `EventUtility.ConstructEvent` with webhook signing secret |
| Idempotency | Store processed event IDs in Redis with 48h TTL |
| Replay protection | Stripe includes timestamp in signature; reject events > 5 min old |
| Timeout handling | Return 200 immediately, process asynchronously |
| IP allowlisting | Optional: restrict webhook endpoint to Stripe IPs in production |

```csharp
// LinearPrecision.Api/Modules/Billing/Services/EntitlementService.cs
public class EntitlementService : IEntitlementService
{
    private readonly AppDbContext _db;
    private readonly IDistributedCache _cache;
    private static readonly TimeSpan CacheTtl = TimeSpan.FromMinutes(5);

    public async Task<PlanLimits> GetPlanLimits(Guid workspaceId)
    {
        var cacheKey = $"entitlements:{workspaceId}";
        var cached = await _cache.GetStringAsync(cacheKey);
        if (cached is not null)
            return JsonSerializer.Deserialize<PlanLimits>(cached)!;

        var subscription = await _db.Subscriptions
            .Include(s => s.Plan)
            .FirstOrDefaultAsync(s => s.WorkspaceId == workspaceId);

        var plan = subscription?.Plan
            ?? await _db.Plans.FirstAsync(p => p.Name == "Free");

        var limits = new PlanLimits
        {
            PlanName = plan.Name,
            MaxMembers = plan.MaxMembers,
            MaxProjects = plan.MaxProjects,
            MaxStorageBytes = plan.MaxStorageBytes,
            MaxAutomations = plan.MaxAutomations,
            HasAi = plan.HasAi,
            HasAdvancedReports = plan.HasAdvancedReports,
            HasCustomFields = plan.HasCustomFields,
            HasTimeline = plan.HasTimeline,
            Has2fa = plan.Has2fa,
            HasSaml = plan.HasSaml,
            HasAuditLog = plan.HasAuditLog
        };

        await _cache.SetStringAsync(cacheKey,
            JsonSerializer.Serialize(limits),
            new DistributedCacheEntryOptions
            {
                AbsoluteExpirationRelativeToNow = CacheTtl
            });

        return limits;
    }

    public async Task<bool> CanAddMember(Guid workspaceId)
    {
        var limits = await GetPlanLimits(workspaceId);
        if (limits.MaxMembers == -1) return true;  // Unlimited

        var currentCount = await _db.WorkspaceMemberships
            .CountAsync(m => m.WorkspaceId == workspaceId);

        return currentCount < limits.MaxMembers;
    }

    public async Task<bool> CanCreateProject(Guid workspaceId)
    {
        var limits = await GetPlanLimits(workspaceId);
        if (limits.MaxProjects == -1) return true;

        var currentCount = await _db.Projects
            .CountAsync(p => p.WorkspaceId == workspaceId && !p.IsDeleted);

        return currentCount < limits.MaxProjects;
    }

    public async Task<bool> CanCreateAutomation(Guid workspaceId)
    {
        var limits = await GetPlanLimits(workspaceId);
        if (limits.MaxAutomations == -1) return true;

        var currentCount = await _db.AutomationRules
            .CountAsync(a => a.WorkspaceId == workspaceId && a.IsActive);

        return currentCount < limits.MaxAutomations;
    }

    public async Task<bool> CanUseFeature(Guid workspaceId, string featureName)
    {
        var limits = await GetPlanLimits(workspaceId);

        return featureName switch
        {
            "ai"               => limits.HasAi,
            "advanced_reports"  => limits.HasAdvancedReports,
            "custom_fields"    => limits.HasCustomFields,
            "timeline"         => limits.HasTimeline,
            "saml"             => limits.HasSaml,
            "audit_log"        => limits.HasAuditLog,
            _                  => true  // Unknown features default to allowed
        };
    }

    public async Task<long> GetRemainingStorage(Guid workspaceId)
    {
        var limits = await GetPlanLimits(workspaceId);
        if (limits.MaxStorageBytes == -1) return long.MaxValue;

        var usedBytes = await _db.FileAttachments
            .Where(f => f.WorkspaceId == workspaceId)
            .SumAsync(f => f.FileSize);

        return Math.Max(0, limits.MaxStorageBytes - usedBytes);
    }

    public async Task<UsageSummary> GetUsageSummary(Guid workspaceId)
    {
        var limits = await GetPlanLimits(workspaceId);

        return new UsageSummary
        {
            Members = new UsageMetric
            {
                Current = await _db.WorkspaceMemberships
                    .CountAsync(m => m.WorkspaceId == workspaceId),
                Limit = limits.MaxMembers
            },
            Projects = new UsageMetric
            {
                Current = await _db.Projects
                    .CountAsync(p => p.WorkspaceId == workspaceId && !p.IsDeleted),
                Limit = limits.MaxProjects
            },
            StorageBytes = new UsageMetric<long>
            {
                Current = await _db.FileAttachments
                    .Where(f => f.WorkspaceId == workspaceId)
                    .SumAsync(f => f.FileSize),
                Limit = limits.MaxStorageBytes
            },
            Automations = new UsageMetric
            {
                Current = await _db.AutomationRules
                    .CountAsync(a => a.WorkspaceId == workspaceId && a.IsActive),
                Limit = limits.MaxAutomations
            }
        };
    }
}
```

```csharp
public record PlanLimits
{
    public string PlanName { get; init; } = "Free";
    public int MaxMembers { get; init; }
    public int MaxProjects { get; init; }
    public long MaxStorageBytes { get; init; }
    public int MaxAutomations { get; init; }
    public bool HasAi { get; init; }
    public bool HasAdvancedReports { get; init; }
    public bool HasCustomFields { get; init; }
    public bool HasTimeline { get; init; }
    public bool Has2fa { get; init; }
    public bool HasSaml { get; init; }
    public bool HasAuditLog { get; init; }
}

// Usage summary DTOs
public record UsageSummary
{
    public UsageMetric Members { get; init; } = new();
    public UsageMetric Projects { get; init; } = new();
    public UsageMetric<long> StorageBytes { get; init; } = new();
    public UsageMetric Automations { get; init; } = new();
}

public record UsageMetric
{
    public int Current { get; init; }
    public int Limit { get; init; }         // -1 = unlimited
    public double PercentUsed => Limit == -1 ? 0 : (double)Current / Limit * 100;
    public bool IsAtLimit => Limit != -1 && Current >= Limit;
}

public record UsageMetric<T> where T : struct
{
    public T Current { get; init; }
    public T Limit { get; init; }
}
```

### 7.2 Usage Recording Service

```csharp
// LinearPrecision.Api/Modules/Billing/Services/UsageService.cs
public class UsageService : IUsageService
{
    private readonly AppDbContext _db;

    public async Task RecordUsageAsync(
        Guid workspaceId,
        string metricType,
        long value,
        CancellationToken ct = default)
    {
        var subscription = await _db.Subscriptions
            .FirstOrDefaultAsync(s => s.WorkspaceId == workspaceId, ct);

        if (subscription is null) return;  // Free tier — no subscription record

        var today = DateOnly.FromDateTime(DateTime.UtcNow);

        var existingRecord = await _db.UsageRecords
            .FirstOrDefaultAsync(r =>
                r.WorkspaceId == workspaceId &&
                r.SubscriptionId == subscription.Id &&
                r.MetricType == metricType &&
                r.RecordedDate == today, ct);

        if (existingRecord is not null)
        {
            existingRecord.Value = value;
            existingRecord.UpdatedAt = DateTime.UtcNow;
        }
        else
        {
            _db.UsageRecords.Add(new UsageRecord
            {
                Id = Guid.CreateVersion7(),
                WorkspaceId = workspaceId,
                SubscriptionId = subscription.Id,
                MetricType = metricType,
                Value = value,
                RecordedDate = today
            });
        }

        await _db.SaveChangesAsync(ct);
    }

    public async Task<Dictionary<string, long>> GetCurrentUsageAsync(
        Guid workspaceId,
        CancellationToken ct = default)
    {
        var today = DateOnly.FromDateTime(DateTime.UtcNow);

        var records = await _db.UsageRecords
            .Where(r => r.WorkspaceId == workspaceId && r.RecordedDate == today)
            .ToDictionaryAsync(r => r.MetricType, r => r.Value, ct);

        return records;
    }
}
```

## 8. Enforcement Middleware

### 8.1 Entitlement Check MediatR Behavior

```csharp
// LinearPrecision.Shared/Behaviors/EntitlementBehavior.cs
public class EntitlementBehavior<TRequest, TResponse> : IPipelineBehavior<TRequest, TResponse>
    where TRequest : IRequest<TResponse>
{
    private readonly IEntitlementService _entitlements;
    private readonly ITenantContext _tenantContext;

    public async Task<TResponse> Handle(
        TRequest request,
        RequestHandlerDelegate<TResponse> next,
        CancellationToken cancellationToken)
    {
        // Check if request requires entitlement validation
        if (request is IRequiresEntitlement entitlementRequest)
        {
            var workspaceId = _tenantContext.WorkspaceId;

            switch (entitlementRequest.EntitlementType)
            {
                case EntitlementType.AddMember:
                    if (!await _entitlements.CanAddMember(workspaceId))
                        throw new PlanLimitExceededException(
                            "Member limit reached. Upgrade your plan to add more members.");
                    break;

                case EntitlementType.CreateProject:
                    if (!await _entitlements.CanCreateProject(workspaceId))
                        throw new PlanLimitExceededException(
                            "Project limit reached. Upgrade to Pro for unlimited projects.");
                    break;

                case EntitlementType.CreateAutomation:
                    if (!await _entitlements.CanCreateAutomation(workspaceId))
                        throw new PlanLimitExceededException(
                            "Automation limit reached. Upgrade your plan for more automations.");
                    break;

                case EntitlementType.UseFeature:
                    if (!await _entitlements.CanUseFeature(
                        workspaceId, entitlementRequest.FeatureName!))
                        throw new PlanLimitExceededException(
                            $"The '{entitlementRequest.FeatureName}' feature requires a higher plan.");
                    break;
            }
        }

        return await next();
    }
}
```

### 9.2 Trial Flow

```
Day 0:  Workspace created
        → Auto-create subscription: plan=Pro, status="Trialing", trial_ends_at=now+14d
        → Send "Welcome to your Pro trial" email

Day 7:  Hangfire recurring job detects trial halfway
        → Send "7 days left in your trial" email + in-app notification

Day 12: Hangfire job detects trial ending soon
        → Send "Trial ending in 2 days — upgrade now" email
        → In-app banner: "Your trial ends in 2 days"

Day 14: Stripe fires `customer.subscription.trial_will_end`
        → If payment method added: convert to paid subscription
        → If no payment method: downgrade to Free
        → Send appropriate notification

Day 14-21: Grace period
        → Features above Free limits still accessible (read-only for excess)
        → Daily reminder emails

Day 21: Hard enforcement
        → Excess projects set to read-only
        → AI, advanced reports, custom fields, timeline disabled
        → Automations beyond 5 paused
```

### 9.3 Trial Expiry Job

```csharp
// LinearPrecision.Api/Modules/Billing/Jobs/CheckTrialExpiryJob.cs
public class CheckTrialExpiryJob
{
    private readonly AppDbContext _db;
    private readonly IMediator _mediator;
    private readonly IDistributedCache _cache;

    [AutomaticRetry(Attempts = 3)]
    public async Task Execute()
    {
        var now = DateTime.UtcNow;

        // Find expired trials
        var expiredTrials = await _db.Subscriptions
            .Where(s => s.Status == "Trialing" && s.TrialEndsAt <= DateOnly.FromDateTime(now))
            .Include(s => s.Plan)
            .ToListAsync();

        foreach (var sub in expiredTrials)
        {
            // Check if Stripe subscription has payment method
            var stripeSubService = new SubscriptionService();
            var stripeSub = await stripeSubService.GetAsync(sub.StripeSubscriptionId);

            if (stripeSub.DefaultPaymentMethodId is not null)
            {
                // Has payment — Stripe will auto-convert to paid
                sub.Status = "Active";
            }
            else
            {
                // No payment — downgrade to Free
                var freePlan = await _db.Plans.FirstAsync(p => p.Name == "Free");
                sub.PlanId = freePlan.Id;
                sub.Status = "Active";  // Active on Free plan

                await _cache.RemoveAsync($"entitlements:{sub.WorkspaceId}");
                await _mediator.Publish(new TrialExpired(sub.WorkspaceId));
            }

            await _db.SaveChangesAsync();
        }

        // Send "trial ending soon" notifications (2 days before)
        var endingSoon = await _db.Subscriptions
            .Where(s => s.Status == "Trialing"
                && s.TrialEndsAt == DateOnly.FromDateTime(now.AddDays(2)))
            .ToListAsync();

        foreach (var sub in endingSoon)
        {
            await _mediator.Publish(new TrialEndingSoon(sub.WorkspaceId, sub.TrialEndsAt!.Value));
        }
    }
}

// Hangfire registration in Program.cs
RecurringJob.AddOrUpdate<CheckTrialExpiryJob>(
    "check-trial-expiry",
    job => job.Execute(),
    Cron.Daily(hour: 6, minute: 0));  // Run at 06:00 UTC daily
```

## 10. Dunning (Failed Payments)

### 10.1 Dunning Flow

```
Day 0:  invoice.payment_failed
        → Set status = "PastDue"
        → Email: "Payment failed — please update your card"
        → In-app banner: "Payment issue — update billing info"

Day 3:  Stripe automatic retry #1
        → If success: clear PastDue, resume normal
        → If fail: email reminder

Day 7:  Stripe automatic retry #2
        → If fail: email "Action required — subscription at risk"
        → Set status = "Unpaid" → read-only mode for non-Free features

Day 14: Stripe automatic retry #3 (final)
        → If fail: email "Final notice"

Day 21: Hangfire job detects subscription unpaid > 21 days
        → Cancel Stripe subscription
        → Set status = "Cancelled"
        → Downgrade to Free plan
        → Email: "Subscription cancelled — your workspace is now on Free"
```

### 10.2 Dunning State Machine

| Current Status | Event | New Status | User Impact |
|---------------|-------|-----------|-------------|
| `Active` | `invoice.payment_failed` | `PastDue` | Full access continues |
| `PastDue` | `invoice.payment_succeeded` | `Active` | Normal access restored |
| `PastDue` | 7 days elapsed, still failing | `Unpaid` | Read-only mode for paid features |
| `Unpaid` | `invoice.payment_succeeded` | `Active` | Full access restored |
| `Unpaid` | 21 days total from first failure | `Cancelled` | Downgraded to Free |
| `Cancelled` | User re-subscribes via Checkout | `Active` | Full access restored |

### 10.3 Grace Period Behavior

| Status | Duration | Feature Access | Data Access |
|--------|----------|---------------|-------------|
| **PastDue** | Days 0–7 | Full access to all paid features | Full read/write |
| **Unpaid** | Days 7–21 | Paid features in read-only mode | Read only for excess data |
| **Cancelled** | After day 21 | Downgraded to Free limits | Read-only for 30 days, then archive |

## 11. Proration

### 11.1 Upgrade Proration

Stripe handles proration automatically. When a workspace upgrades mid-cycle:

- **Immediate access** to new plan features.
- **Prorated charge** for the remainder of the current billing period.
- Example: Pro ($12/seat) → Business ($24/seat) on day 15 of 30-day cycle:
  - Unused Pro credit: $12 x (15/30) = $6 refunded
  - Remaining Business charge: $24 x (15/30) = $12 charged
  - Net charge: $12 - $6 = $6

```csharp
// Upgrade implementation — Stripe handles proration
var stripeSubService = new SubscriptionService();
await stripeSubService.UpdateAsync(stripeSubscriptionId, new SubscriptionUpdateOptions
{
    Items = new List<SubscriptionItemUpdateOptions>
    {
        new()
        {
            Id = existingItemId,
            Price = newPriceId
        }
    },
    ProrationBehavior = "create_prorations"  // Default — creates invoice line items
});
```

### 11.2 Downgrade Behavior

Downgrades take effect at the **end of the current billing period** to honor what the customer already paid for:

```csharp
// Schedule downgrade for end of period
await stripeSubService.UpdateAsync(stripeSubscriptionId, new SubscriptionUpdateOptions
{
    Items = new List<SubscriptionItemUpdateOptions>
    {
        new()
        {
            Id = existingItemId,
            Price = downgradePriceId
        }
    },
    ProrationBehavior = "none"  // No immediate charge/refund
});
```

### 11.3 Seat Changes

| Change | Billing Effect | Timing |
|--------|---------------|--------|
| Add seats | Prorated charge for remainder of period | Immediate |
| Remove seats | No refund; reduction at next renewal | End of period |
| Bulk seat change | Prorated net difference | Immediate for additions |
