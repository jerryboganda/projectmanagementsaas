# Feature Execution Plan

Use this skill for multi-step or cross-feature work.

## Workflow

1. State target behavior and affected routes/components.
2. Split work into milestones with explicit ownership boundaries.
3. Mark what can run in parallel and what must stay serialized.
4. Define validation gates before edits begin.
5. Update `docs/PLANS.md` and record durable decisions in `docs/decision-log.md`.
